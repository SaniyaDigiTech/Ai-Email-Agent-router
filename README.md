# Ai-Email-Agent-router


# 🤖 AI Email Router

An Agentic AI automation built with **n8n, Gmail, and OpenAI** that reads incoming emails, understands their content, classifies them, and routes them automatically.

## 🔄 Workflow

Gmail → AI Agent → Structured Output → Switch → Sales / Support / General → Google Sheets

## ✨ Features

- 📧 Gmail email trigger
- 🤖 AI-powered email classification
- 🏷️ Sales / Support / General categories
- ⚡ Priority detection
- 📝 Automatic summary and recommended action
- 🔀 Conditional routing with Switch
- 📊 Google Sheets logging

## 🛠️ Tech Stack

- n8n
- OpenAI
- Gmail
- Google Sheets

## 🎯 Purpose

To automate email understanding, classification, routing, and logging using an Agentic AI workflow.
